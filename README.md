# jakedami.co

Umbrella monorepo for everything living under jakedami.co. Each surface is an
independent Cloudflare project pointed at this repo with a different root
directory — deploys never interfere with each other.

| Path | Deploys to | What |
|------|-----------|------|
| `portfolio/` | `jakedami.co` (CF Pages) | Root site. Placeholder now; personal portfolio later. |

Future integrations get their own top-level folder + CF project, same pattern.
